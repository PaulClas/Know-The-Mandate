# HTTP API reference

> Generated by `make reference` from the FastAPI OpenAPI document; do not edit by hand. The full machine-readable schema is [../specifications/openapi.json](../specifications/openapi.json) and, when the API runs, `/docs` and `/openapi.json`.

Auth: `/bank/*` calls need a DPoP-bound access token (`Authorization: DPoP <token>` plus a `DPoP` proof header); `/api/*` calls use a demo session bearer token (`POST /api/session`, demo only). Money is always integer minor units (cents).

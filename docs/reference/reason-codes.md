# Reason codes

> Generated by `make reference` from `kym.policy`; do not edit by hand.

Decisions are one of: `ALLOW`, `DENY`, `REQUIRE_HUMAN_APPROVAL`, `REFER_TO_RISK_REVIEW`. Every denial carries one or more reason codes plus the failed check ids, and the same codes are stored in the evidence ledger.

| Code | Kind | Meaning |
|---|---|---|
| `AGENT_NOT_VERIFIED` | base | The agent is not in VERIFIED status in the agent registry. |
| `AGENT_SUSPENDED` | base | The agent was suspended, restricted or revoked by the bank. |
| `INVALID_TOKEN` | base | The access token failed signature, expiry, audience, revocation or DPoP-proof checks. |
| `INVALID_ACTOR_BINDING` | base | The token's actor/client does not match the agent named in the mandate. |
| `TOKEN_SCOPE_INSUFFICIENT` | base | The token's OAuth scope does not cover the requested API action. |
| `MANDATE_NOT_FOUND` | base | No mandate matches the identifier carried in the token or request. |
| `MANDATE_EXPIRED` | base | The mandate's validity window has ended. |
| `MANDATE_REVOKED` | base | The customer (or bank) revoked the mandate; takes effect on the next request. |
| `MANDATE_VERSION_MISMATCH` | base | The token is bound to a different mandate version or digest, or the mandate was superseded by an amendment. |
| `RESOURCE_NOT_AUTHORIZED` | base | The account or resource is not listed in the matching permission. |
| `ACTION_NOT_AUTHORIZED` | base | No permission in the mandate covers this action, or the action is prohibited. |
| `PURPOSE_NOT_AUTHORIZED` | base | The stated purpose differs from the mandate's purpose. |
| `BENEFICIARY_NOT_AUTHORIZED` | base | The beneficiary is not in the permission's allowed list. |
| `CURRENCY_NOT_AUTHORIZED` | base | The currency is not the one the permission allows. |
| `TRANSACTION_LIMIT_EXCEEDED` | base | The amount exceeds the per-transaction maximum (or the amount is not a positive integer in minor units). |
| `DAILY_LIMIT_EXCEEDED` | base | The cumulative daily total would exceed the mandate's daily limit. |
| `MONTHLY_LIMIT_EXCEEDED` | base | The cumulative monthly total would exceed the mandate's monthly limit. |
| `DELEGATION_NOT_ALLOWED` | base | The mandate does not permit delegation, or the maximum depth is reached. |
| `DELEGATION_EXCEEDS_PARENT` | base | A child mandate is not a strict attenuation of its parent. |
| `HUMAN_APPROVAL_REQUIRED` | base | The amount is above the human-approval threshold; a valid, single-use approval is needed. |
| `RISK_THRESHOLD_EXCEEDED` | base | The risk score is over the deny threshold, or the synthetic watch-list was hit (demo data, not real screening). |
| `CUSTOMER_NOT_VERIFIED` | extension | The principal's KYC status is not VERIFIED. |
| `ACCOUNT_RESTRICTED` | extension | The account or customer carries a restriction that blocks the action. |
| `MANDATE_NOT_YET_VALID` | extension | The mandate's start time is in the future. |
| `MANDATE_SUSPENDED` | extension | The mandate is temporarily suspended and may be resumed. |
| `MERCHANT_NOT_AUTHORIZED` | extension | The merchant is not in the permission's allowed list. |
| `DELEGATION_CYCLE` | extension | The delegation lineage contains a cycle. |
| `APPROVAL_INVALID` | extension | The approval is missing, expired, already consumed, or bound to a different operation. |
| `POLICY_INPUT_UNVERIFIABLE` | extension | A required policy input (for example risk information) is unavailable, so the engine fails closed. |
| `RISK_REVIEW_REQUIRED` | extension | The risk score is over the review threshold; the transaction is referred to review instead of being auto-decided. |
